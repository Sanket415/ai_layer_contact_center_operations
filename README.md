# AI Layers — Customer Support

Event-driven, config-driven AI layer for bank contact-centre colleagues. It consumes Amazon Connect–style transcripts, classifies Query / Concern / Complaint with an FCA-style decision tree, and returns point-in-time coaching plus a draft log via API. LangGraph parent orchestrator with specialist subgraphs. Human-in-the-loop — no auto-filing.

See [docs/architecture.md](docs/architecture.md) for the current architecture.
